# Creator Analytics Dashboard

## Goal

Create a centralized analytics system for my social media content.

## Platforms

- Buffer
- YouTube
- TikTok
- Instagram
- Twitch — future

## Planned Features

- Automatically import posts
- Collect post metrics over time
- Label posts by game and content type
- Compare platforms
- Analyze posting days and times
- Analyze posting frequency
- Recommend future posting schedules
- Review proposed Buffer schedule changes
- Update Buffer after approval
- Add AI-assisted content analysis later

## Technology

- Buffer API
- Make.com
- Supabase
- Looker Studio
- YouTube Analytics API
- Instagram Insights API
- TikTok API where available
